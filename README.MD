Ви маєте функцію <code style="background-color: #F0F0F0">fetchUserData(userId)</code>, яка повертає проміс із даними користувача (емуляція запиту до API).  

Потрібно написати функцію <code style="background-color: #F0F0F0">getUsersData(userIds)</code>, яка:  
1. Приймає масив <code style="background-color: #F0F0F0">userIds</code>.  
2. Повертає <b>проміс</b>, що резолвиться в масив об’єктів користувачів.  
3. Якщо хоча б один запит завершується з помилкою — у результаті має повернутись <b>масив успішних відповідей і масив помилок</b>.
