Даний масив чисел const arr = [1, 2, 3, -1, -2, -3];  

&bull; Потрібно написати функцію, яка поверне новий масив, що містить лише позитивні числа. Для цього:  
&bull; Створюємо функцію з довільною назвою.  
&bull; Функція приймає масив як параметр.  
&bull; В тілі функції створюємо порожній масив (приклад: const exampleArr = []).  
&bull; Якщо масив, переданий як параметр у функцію, є порожнім, то повертаємо відповідне повідомлення.  
&bull; Перебираємо циклом масив, який передано як параметр (використовуємо цикл for).  
&bull; В тілі циклу перевіряємо, чи є поточний елемент позитивним числом чи від'ємним (if).  
&bull; Якщо число позитивне, то додаємо його до раніше створеного масиву за допомогою функції push (приклад exampleArr.push(currentPositiveNumber)).  
&bull; Після виконання циклу перевіряємо масив, який наповнили лише позитивними значеннями.  
&bull; Якщо він не є порожнім, то повертаємо цей масив.  
&bull; Якщо він порожній, повертаємо null.
