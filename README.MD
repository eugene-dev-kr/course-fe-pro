Вимоги до сторінки:
1. <b>Навігаційна панель (Navbar)</b>  
   &bull; Логотип або ім'я у лівій частині.  
   &bull; Посилання на секції: About, Skills, Projects, Contact.  
   &bull; Панель повинна бути фіксованою зверху.  
2. <b>Секція "Про себе" (About)</b>  
   &bull; икористайте container для структури.  
   &bull;Додайте свою фотографію (або заглушку) в одній колонці і текстовий опис в іншій.  
   &bull; Використайте row та col для розподілу.  
3. <b>Секція "Навички" (Skills)</b>  
   &bull; Додайте список навичок (наприклад, HTML, CSS, JavaScript) у вигляді прогрес-барів.  
   &bull; Використовуйте компонент progress.  
4. <b>Секція "Проєкти" (Projects)</b>  
   &bull; Створіть карточки (card) для кожного проєкту.  
   &bull; У карточках використовуйте зображення, заголовок та короткий опис.  
5. <b>Секція "Контакти" (Contact)</b>  
   &bull; Форма з полями: ім'я, email, повідомлення та кнопка "Submit".  
   &bull; Використайте form-control для інпутів.  
6. <b>Footer</b>  
   &bull; Додайте футер з текстом типу "© 2024 Your Name. All Rights Reserved."  
   &bull; Використайте text-center для центрування.  
<b>Додаткові вимоги:</b>  
   &bull; Використовуйте класи Bootstrap для стилізації, уникайте додавання власних CSS-стилів.  
   &bull; Сторінка повинна виглядати добре на мобільних пристроях (перевірте адаптивність).
