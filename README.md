1. Створіть класовий компонент <code style="background-color: #F0F0F0">Timer</code>, який:  
    &bull; Відображає <b>число секунд</b>, що пройшли з моменту монтування компонента.  
    &bull; Має кнопки <b>Start</b>, <b>Stop</b> і <b>Reset.</b>  


2. Використайте методи життєвого циклу:  
   &bull; <b>componentDidMount</b> – щоб запустити інтервал, який збільшує лічильник кожну секунду.  
   &bull; <b>componentDidUpdate</b> – щоб у консоль виводилось повідомлення "Updated: <значення>", коли змінюється кількість секунд.  
   &bull; <b>componentWillUnmount</b> – щоб очищати інтервал, коли компонент видаляється.  
Додайте кнопку <b>Unmount Timer</b>, яка повністю видаляє компонент з DOM (через умовний рендеринг у батьківському компоненті).  

<b>Додатково:</b>  
   &bull; Реалізуйте збереження стану таймера у LocalStorage (щоб при перезавантаженні сторінки час відновлювався).  
   &bull; Зробіть стилізацію через CSS (наприклад, при зупиненому таймері цифри стають червоними).
